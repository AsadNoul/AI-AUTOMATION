Installation

There are multiple ways to install n8n depending on your environment and preferences.

Docker Installation (Recommended)

The easiest way to get started is with Docker:

docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

NPM Installation

Install globally via npm:

npm install n8n -g
n8n start

Desktop Application

Download the desktop app from n8n.io for a native experience.

Success! After installation, navigate to http://localhost:5678 to access n8n.

Core Concepts

Workflows

A workflow is a series of connected nodes that define an automation process. Each workflow consists of:

  • Trigger Node: Starting point that initiates the workflow
  • Processing Nodes: Transform data, make decisions, or call APIs
  • Action Nodes: Perform final actions like sending emails or updating databases

Nodes

Nodes are the building blocks of workflows. Key node types include:

  • Trigger Nodes: Webhook, Schedule, Email, etc.
  • AI Nodes: OpenAI, Anthropic, Hugging Face
  • Logic Nodes: IF, Switch, Merge
  • Data Nodes: Set, Function, Code
  • Integration Nodes: 400+ app integrations

Data Flow

Data flows between nodes in JSON format:

[
  {
    "json": {
      "field1": "value1",
      "field2": "value2"
    }
  }
]

Building Workflows

Step 1: Add a Trigger

Every workflow starts with a trigger. Common triggers:

  • Webhook: Trigger via HTTP requests
  • Schedule: Run on a schedule (cron)
  • Manual: For testing and development

Step 2: Add Processing Nodes

Connect nodes to process your data. Use expressions to reference data:

// Access current node data
{{ $json.propertyName }}

// Reference other nodes
{{ $node["NodeName"].json }}

// Current timestamp
{{ $now }}

Step 3: Add Actions

Complete your workflow with action nodes that perform the final operations.

AI Integration

OpenAI Integration

Configure the OpenAI node for chat completions:

{
  "model": "gpt-4",
  "messages": [
    {
      "role": "system",
      "content": "You are a helpful assistant"
    },
    {
      "role": "user",
      "content": "{{ $json.userQuery }}"
    }
  ]
}

Anthropic (Claude) Integration

{
  "model": "claude-3-opus-20240229",
  "max_tokens": 1024,
  "messages": [
    {
      "role": "user",
      "content": "Analyze: {{ $json.data }}"
    }
  ]
}
API Keys Required: You'll need API keys from AI providers. Store them securely in n8n credentials.

Data Management

Data Transformation

Use the Function node for complex transformations:

const items = $input.all();
return items.map(item => ({
  json: {
    id: item.json.id,
    processed: item.json.value * 2
  }
}));

Error Handling

Always include error handling in production workflows:

try {
  const result = await riskyOperation();
  return [{ json: { success: true, data: result } }];
} catch (error) {
  return [{ json: { success: false, error: error.message } }];
}

Best Practices

Security

  • Store API keys in n8n credentials, never hardcode
  • Use webhook authentication
  • Sanitize user inputs before AI processing
  • Implement rate limiting

Performance

  • Use batch processing when possible
  • Implement caching for repeated queries
  • Monitor API usage and costs
  • Use appropriate AI models (smaller for simple tasks)

Reliability

  • Add error handling to all workflows
  • Implement retry logic for API calls
  • Monitor workflow executions
  • Test with various data scenarios

Troubleshooting

Common Issues

Workflow Not Triggering

Check that:

  • Workflow is activated
  • Trigger is properly configured
  • Webhook URL is correct

AI Response Errors

Verify:

  • API key is valid and has credits
  • Model name is correct
  • Prompt is within token limits
  • Rate limits not exceeded

Data Not Flowing

Common causes:

  • Incorrect expression syntax
  • Node returning empty array
  • Type mismatch in data
